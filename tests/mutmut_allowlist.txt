# function-granular diff gate (scripts/mutmut_diff_gate.py) subtracts every id

#
# Only two kinds of survivor belong here, and each entry MUST carry a reason:
#   * equivalent mutants — the mutation produces behaviour indistinguishable
#     from the original, so no test can kill it;
#   * integration-only-covered — the behaviour is exercised only by tests
#     outside mutmut's focused per-module suite (install / capture / auditfix),
#     so the mutant survives the scoped run but is not actually a coverage gap.
#
# Ids look like: setforge.<module>.x_<function>__mutmut_<N>
#            or: setforge.<module>.xǁ<Class>ǁ<method>__mutmut_<N>
#
# Format (id, then a `#` reason):
#   setforge.scalar_merge.x_resolve_scalar__mutmut_4  # equivalent: reordered
#
# An equivalent mutant whose source line carries ONLY equivalent mutants does
# not belong here: excuse it in the source with `# pragma: no mutate` on the
# statement and the reason in a comment above it. The pragma stops mutmut
# generating every mutant that starts on that statement's first line, so the
# entries below stay here: each shares its line (or its multi-line call) with
# mutants the tests do kill, and a pragma would hide those.
#
# mutmut numbers mutants by position inside the function, so editing a function
# above a listed mutant renumbers it: re-check each id of that function with
# `uv run mutmut show <id>`. The gate warns only about an id that no longer
